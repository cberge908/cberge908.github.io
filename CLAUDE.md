## Project Overview

This is a GitHub Pages personal portfolio site built with MkDocs. The source content lives in `about-me/`, and the built site is published to the `gh-pages` branch.

## Development Commands

All MkDocs commands must be run from the `about-me/` directory:

```bash
cd about-me

# Install dependencies
pip install -r ../requirements.txt

# Local development server (hot-reload at http://127.0.0.1:8000)
mkdocs serve

# Build static site to about-me/site/
mkdocs build

# Build and deploy to gh-pages branch
mkdocs gh-deploy
```

## Architecture

**Source vs. published content:**
- `about-me/docs/` — Markdown source files (edit these)
- `about-me/site/` — Built HTML output (gitignored, generated by `mkdocs build`)
- Root-level `index.html`, `css/`, `js/`, `img/` etc. — The published GitHub Pages artifacts (also gitignored per `.gitignore`); these are deployed to `gh-pages` via `mkdocs gh-deploy`

**Branches:**
- `edit` — Working branch for content changes
- `main` — Source branch
- `gh-pages` — Auto-generated deployment branch (managed by `ghp-import` via `mkdocs gh-deploy`)

**MkDocs config:** `about-me/mkdocs.yml` — controls site name, theme (mkdocs default with auto dark/light mode toggle).

**Python environment:** `.venv/` at repo root (Python 3.14).

## Content

All site content is in `about-me/docs/index.md`. This is currently the only page. New pages can be added as additional `.md` files under `about-me/docs/` and referenced in `mkdocs.yml` under the `nav` key.
